## 1. Silkscreen (`Silkscreen-Regular.ttf`) — Unified UI Pixel Font Family
- **Role**: The single unified pixel font family used for **all** UI text across all screens and hierarchy sizes (Primary Menu Items, Medium & Small Menu Items, Subtitle, Caption, Splash Cards, Loading Status, Headers, Settings, Stage Select, Lore Codex, How to Play, Quit Confirmation, and Version Label), applied exclusively through `res://ui/theme/haliya_theme.tres`.
- **Author**: Jason Kottke
- **Source**: https://github.com/google/fonts/tree/main/ofl/silkscreen
- **License**: SIL Open Font License 1.1 (OFL-1.1)
- **Copyright**: Copyright 2022 The Silkscreen Project Authors (https://github.com/kottke/silkscreen-font).

## 2. Press Start 2P (`PressStart2P-Regular.ttf`) — Offline Carved Title Generator Mask
- **Role**: Used offline by `tools/generate_ui_assets.py` as the base glyph mask before procedural chiseling, hairline cracking, and moss/wear pass for `res://assets/ui/title_haliya.png`. Not used for live UI text.
- **Author**: Cody "CodeMan38" Boisclair
- **Source**: https://github.com/google/fonts/tree/main/ofl/pressstart2p
- **License**: SIL Open Font License 1.1 (OFL-1.1)
- **Copyright**: Copyright (c) 2011, Cody "CodeMan38" Boisclair (cody@zone38.net), with Reserved Font Name "Press Start" and "Press Start 2P".

## 3. Noto Sans Tagalog (`NotoSansTagalog-Regular.ttf`) — Pre-Colonial Baybayin Script
- **Role**: Unicode Tagalog/Baybayin script block (`U+1700..U+171F`) glyph rendering in the Lore Codex and execution prompts.
- **Author**: Google LLC
- **Source**: https://github.com/notofonts/tagalog
